Seed import

        

          Type or generate a seed. "Import" only enables once the field holds a value that passes
          the same validation Address.importBySeed() itself enforces.
        

        

          
          
          
        

        

      


      

        
Hex import

        

          Type or generate a raw ed25519 private key. "Import" only enables once the field holds a
          value that passes the same validation Address.importByHex() itself
          enforces.
        

        

          
          
          
        

        

      


      

        
Mnemonic import

        

          Type or generate a BIP-39 mnemonic. "Import" only enables once the field holds a value
          that passes the same validation Address.importByMnemonic() itself
          enforces.
        

        

          
          
          
        

        

      


      

        
Xaman import

        

          Type or generate a Xaman app "Secret Numbers" backup — 8 groups of 6 digits each.
          "Import" only enables once every group holds a value that passes the same validation
          Address.importByXaman() itself enforces (shape + per-group checksum digit).

Trust line

        

          Opens a trust line for an issued currency via TrustLines.setTokenTrustLine()
          (TrustSet), or authorizes holding an MPT via
          TrustLines.setMptTrustLine() (MPTokenAuthorize) — the MPT
          equivalent of a trust line. Run this from the holder's seed before sending them
          a token/MPT above.
